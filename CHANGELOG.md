# Changelog

## MotoDash Web V2.4
- Recréation de l'interface web à partir des fonctions présentes dans l'archive Android V2.3 fournie.
- Dashboard, télémétrie, historique local, jauge d'inclinaison, calibration, maxima et gestion de sessions.
- Ajout du manifeste PWA, d'un service worker et d'une icône SVG.
- Inclinaison web basée sur `DeviceOrientationEvent.gamma` ; GPS et accélération basés sur les API navigateur.
- Les capteurs web restent expérimentaux et peuvent se comporter différemment de l'application Android.

## V2.6
- Jauge horizontale alignée sur le composant Android LeanGauge().
