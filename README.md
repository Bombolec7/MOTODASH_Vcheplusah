# MotoDash Web V2.6

Version Web/PWA mise à jour à partir du projet Android Studio fourni.

La jauge du Dashboard reprend le composant `LeanGauge()` de `MainActivity.kt` :
- barre horizontale gris `#414854` ;
- 24 graduations, graduation centrale blanche ;
- segment rouge du centre jusqu'à l'angle mesuré ;
- curseur vertical blanc ;
- plage de mesure de -60° à +60°.

Les autres fichiers PWA et les écrans existants sont conservés. Les mesures GPS et capteurs dépendent des API et permissions du navigateur.
